PROTOCOL

What this demo holds fixed

5-foldout-of-fold calibration

The three forecasters see exactly the same acquisition labels, the same 60 evaluation items, and the same budget grid: 0, 1, 3, 7, 15, 31. This interface uses one frozen acquisition order per task; the 10-order grid is evaluated offline.

Beta is the transparent baseline. Online-AIRT and CNP-AIRT load frozen checkpoints; the app does not train or fine-tune. CNP-AIRT is calibrated with the prefit full-BCE anchor calibrator; the diagnostic Brier calibrator is not used. The hidden leaderboard is not used anywhere in this interface.

Brier ALC is the weighted average of Brier scores across the budget grid. Lower is better.
